# ✍️ Quick Note — 快速记录工具

一个基于 Python + Tkinter 的轻量级桌面笔记工具，通过全局热键 `Ctrl+Alt+E` 一键呼出，随时记录灵感、待办、代码片段和学习笔记。

## ✨ 功能特性

- **全局热键呼出** — 按 `Ctrl+Alt+E` 随时唤出记录窗口，无需切换应用
- **标签分类** — 支持 默认、重要、待办、灵感、代码、学习 六种标签
- **全文搜索** — 实时搜索笔记内容、标签和时间
- **筛选过滤** — 按标签快速过滤笔记列表
- **收藏标记** — 一键收藏重要笔记，置顶显示
- **暗色/亮色主题** — 支持切换，自动记忆偏好
- **右键菜单** — 编辑、复制、修改标签、收藏、删除一步到位
- **导出功能** — 导出为 TXT 和 JSON 格式
- **数据本地存储** — 所有数据保存在本地 `notes.json`，无需联网

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows 操作系统（热键依赖 Win32 API）

### 运行

```bash
python quick_note.py
```

启动后程序在后台运行，按 `Ctrl+Alt+E` 呼出记录窗口。

### 退出

在终端按 `Ctrl+C` 退出程序。

## 🎨 界面预览

### 暗色主题
- 中性深灰背景层级设计，舒适护眼
- 输入框聚焦时显示紫色发光边框
- 卡片通过背景色差区分，无生硬边框
- 胶囊形筛选标签，现代简洁

### 亮色主题
- 点击右上角 🌙/☀️ 图标即可切换主题
- 主题偏好自动保存到 `config.json`

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Alt+E` | 全局呼出/置顶窗口 |
| `Ctrl+Enter` | 保存笔记 |
| `Esc` | 关闭窗口 |
| `Double Click` | 编辑笔记 |
| `Right Click` | 打开右键菜单 |

## 🎯 设计理念

遵循「做减法」与「做柔化」的设计思路：

- **去边框** — 去除冗余分割线和生硬边框，通过留白和底色差区分模块
- **去分割线** — 用间距代替线条，界面更清爽
- **柔化对比** — 中性深灰背景 + 紫色强调色，Focus 时才显示发光边框
- **层级分明** — 通过不同灰度的背景色区分 Header / 输入区 / 列表区 / Footer
- **空状态引导** — 无笔记时直接引导用户在输入框开始记录
