# ✍️ Quick Note · Command Center Edition

一个基于 Python + Tkinter 的极简桌面笔记工具，采用 **Command Center** 交互设计。全局热键 `Ctrl+Alt+E` 一键呼出，底部输入即记，支持 `#标签` 自然语言分类和 `/搜索` 即时过滤。

## ✨ 功能特性

- **全局热键** — `Ctrl+Alt+E` 随时唤出，无需切换应用
- **底部命令栏** — 输入文字按 `Enter` 即记，无需点按钮
- **标签选择器** — 命令栏内置标签下拉菜单，输入前直接选择分类
- **自然语言标签** — 输入 `#重要` `#代码` `#学习` 自动识别并覆盖
- **即时搜索** — 输入 `/关键词` 切换搜索模式，实时过滤
- **标签筛选** — 顶部胶囊标签一键过滤
- **收藏** — 右键收藏重要笔记，带 ⭐ 标识
- **置顶** — 右键置顶笔记，始终排在最前面（📌 标识）
- **时间轴视图** — 单列时间线布局，彩色圆点标识分类
- **双主题** — 暗色/亮色一键切换，自动记忆偏好
- **呼吸水晶** — 空状态动画引导
- **环境光背景** — 深色弥散光晕营造沉浸感
- **使用指南** — 首次启动自动弹出，可勾选不再显示
- **OCR 截屏识别** — 点击 📷 按钮，框选屏幕区域自动识别文字，支持多行内容
- **今日计划 + 提醒** — `!HH:MM` 创建定时提醒，到时自动弹窗，📋 查看今日计划
- **浮动球** — 桌面圆形悬浮球，左键点击呼出，拖拽移动，右键快捷菜单，自动吸边
- **数据本地** — 所有数据保存在 `notes.json`，无需联网

## 🚀 快速开始

### 环境要求

- Python 3.8+
- Windows 操作系统（热键依赖 Win32 API）

### 运行

```bash
python quick_note.py
```

启动后在后台运行，按 `Ctrl+Alt+E` 呼出窗口。

### 退出

终端按 `Ctrl+C` 退出程序。

## 📖 使用说明

### 基本操作

| 操作 | 说明 |
|------|------|
| **输入文字 + Enter** | 创建一条笔记 |
| **点击标签选择器** | 弹出菜单选择分类（默认→重要→待办...） |
| **输入 `#标签名`** | 自动为笔记添加标签，覆盖选择器的标签 |
| **输入 `/关键词`** | 切换到搜索模式，实时过滤笔记 |
| **输入 `!HH:MM 内容`** | 创建定时提醒（如 `!14:00 开会`） |
| **点击顶部标签** | 按分类筛选笔记列表 |
| **单击卡片** | 选中高亮 |
| **双击卡片** | 打开编辑窗口 |
| **右键卡片** | 弹出菜单（收藏、置顶、编辑、复制、改标签、删除） |
| **点击 `?` 按钮** | 重新打开使用指南 |
| **Esc** | 关闭窗口 |

### 标签选择器

命令栏中有一个标签下拉菜单（`📌 默认`），点击后弹出所有可选标签：

```
✎  [📌 默认 ▾]  [输入笔记...]  ↵
```

- 点击选择标签 → 之后创建的笔记默认使用该标签
- 输入中加 `#标签名` → 覆盖选择器的标签
- 选择器会保持选中状态，下次输入无需重新选择

### 自然语言标签示例

```
修复登录页的 CSS bug #代码        → 标签：代码
明天开会讨论新方案 #重要            → 标签：重要
买牛奶                             → 标签：选择器当前选中的标签
```

支持的标签：`#默认` `#重要` `#待办` `#灵感` `#代码` `#学习`

> 💡 `#标签` 会被自动从内容中移除，笔记内容保持干净。

### 搜索模式

在命令栏输入 `/` 开头即进入搜索模式（左侧图标变为 🔍）：

```
/bug          → 搜索包含 "bug" 的笔记
/2024-01      → 搜索特定日期的笔记
/代码         → 搜索包含 "代码" 的笔记
```

清空输入或删除 `/` 即自动回到笔记模式。

### 右键菜单

右键点击任意笔记卡片可进行以下操作：

- ⭐ 收藏 / 💔 取消收藏
- 📌 置顶 / 📌 取消置顶（置顶笔记始终排在最前）
- ✏️ 编辑（打开编辑窗口，可修改内容和标签）
- 📋 复制内容到剪贴板
- 🏷️ 修改标签
- 🗑️ 删除

### 主题切换

点击右上角 ☀/🌙 图标切换暗色/亮色主题。主题偏好自动保存。

### 导出笔记

点击右上角 ↗ 图标，选择目录后导出为 TXT 文件。

### 📷 OCR 截屏识别

点击右上角 📷 按钮启动 OCR 识别流程：

1. **框选区域** — 屏幕变暗后，拖拽鼠标框选要识别的区域
2. **等待识别** — 弹出进度提示窗口，显示动画进度条
3. **查看结果** — 识别完成后自动打开结果查看窗口，显示所有识别文字（支持多行）
4. **操作结果** — 在结果窗口中可以：
   - ✏️ 编辑识别文字
   - 📋 复制到剪贴板
   - 💾 保存为笔记（支持 `#标签` 自动分类）
   - Esc 关闭

> 首次使用需安装依赖：`pip install paddleocr paddlepaddle Pillow`

## 🎨 设计理念

Command Center Edition 采用现代效率工具（Raycast / Notion / Linear）的设计理念：

- **底部输入** — 类似聊天框的输入体验，符合"倾诉-记录"本能
- **标签选择器** — 输入前选好分类，减少后续整理成本
- **模式指示** — ✎ 笔记模式 / 🔍 搜索模式，一眼识别当前状态
- **时间轴布局** — 单列 + 彩色圆点，清晰的时间线视觉
- **去按钮化** — 无需保存按钮，Enter 即记，极简操作
- **环境光氛围** — 深色弥散光晕背景，深邃而非死板
- **呼吸水晶** — 空状态动画引导，等待用户的第一次输入
